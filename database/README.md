# RAVIA Sistemas

## Como configurar o ambiente

1. Instale o XAMPP (ou similar com Apache + PHP + MySQL).
2. Clone este repositório dentro de `htdocs`.
3. No phpMyAdmin, crie um banco vazio chamado `ravia_db`.
4. Vá em "Importar" e selecione o arquivo `database/ravia_db.sql`.
5. Confira o arquivo `config/conexao.php` — ajuste `host`, `port`, `usuario` e `senha` conforme o seu ambiente local.
6. Acesse `localhost/RaviaSistemas/` no navegador.
